# EVERFREEZE 공략 (해답지)

오류 단계를 올리는 **흔적 R-01~R-13**을 모으면 단계가 1 → 5로 오르고, 5단계에서 엔딩이 나옵니다.
아래 순서대로 하면 막힘 없이 엔딩까지 갑니다. (정답·문장은 지금 사이트 기준이며, 퍼즐을 바꾸면 이 문서도 같이 고칩니다.)

- **단계가 오르는 조건**: 구간의 흔적을 모두 모으면 다음 단계
  - 2단계 ← R-01 · R-02 · R-03
  - 3단계 ← R-04 · R-05 · R-06
  - 4단계 ← R-07 · R-08 · R-09 · R-10
  - 5단계(엔딩) ← R-11 · R-12 · R-13
- **추리는 자동**: 필요한 증거가 모이면 사이트가 알아서 완료합니다. (화면에는 안 보임)
- **조작**: 그림을 클릭 · 그림 아래쪽 ▼ = 뒤로 · 아직 안 되는 곳은 그림이 흔들림 · 퍼즐은 오답 3번부터 힌트

| 2 | 로즈메리 → 클로버의 집 → **서랍** | 다이얼 **4 · 1 · 7** | **R-02** 서랍 속 메모 |
| 3 | 로즈메리 → 광장 → **시계** | 클로즈업: **11시 59분**, 바늘은 시계 방향 (기억해 둘 것) | **R-01** 멈춘 시계 |

## 막혔을 때
- **눌렀는데 그림만 흔들린다** → 아직 단계가 모자라거나 잠긴 곳. 위 표의 단계를 먼저 채웁니다.
  - 게시판 · 새집 장치: 2단계 / 회전 선반 · 작업대 · 우편함 · 자료 보관실: 3단계 / 오래된 기록 · 편지: 4단계 / 아틀리에 작업대: 편지 신호(P-LETTER)를 풀고 아리아와 대면한 뒤 (순서 고정: 편지 신호 → 아리아 대면 → 아틀리에 작업대)
- **자료 보관실 문이 안 열린다** → 3단계 + 열람실 대출 장부 퍼즐을 풀어야 합니다.
- **비밀 기록실 입구가 없다** → 자료 보관실의 기록 조각 퍼즐을 풀면 나타납니다.
- **아리아가 대면하지 않는다** → 4단계 + 추리 MAIN 3개가 모두 필요합니다.
  - MAIN-01 = 3번(R-01) · 4번(R-03) · 11번(C-01) / MAIN-02 = 10번(C-02) · 18번(C-03) / MAIN-03 = 5번(LIB-BLOCK) · 8번(R-05)
  - 특히 **5번 출입 제한 안내문**과 **18번 관찰일지**를 빠뜨리기 쉽습니다.
- **퍼즐을 3번 틀리면** 창 아래에 힌트 문장이 나옵니다. 창을 닫았다 다시 열어도 힌트는 남아 있습니다.
